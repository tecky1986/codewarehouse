## 8. 优化建议（按优先级）

1. **箱数估算去掉 +2，改为按需开箱**
   - 现状：`jobs._estimate_count` 固定 `need + 2`，本表直接给 5 箱。
   - 建议：先按 max(体积下界, 载重下界) 开箱；只在有未分配且当前箱已满时再加 1 箱。前端「上限 0 = 不限」应显示预估箱数。

2. **装填策略改为「先填满再开新箱」**
   - 现状：候选箱按序号全开，算法在 5 个空箱上并行洒货，单箱体积利用率卡在 ~45%。
   - 建议：First-Fit Decreasing：大件（FD-1 / IB-1 / GB-3）按体积降序，优先塞已占用箱；同型（GB-3 28 件全相同）连续铺满一层再上第二层。

3. **放置与校验模型对齐**
   - 现状：maxspace 能摆进去，卸货回放大量 E106/E103。
   - 建议：放置时用与 `verify.py` 同一套卸货路径检查；或放置后对每箱跑 verify，失败则回退该件。否则「完成率高」的方案现场无法卸。

4. **同型分组与默认规则**
   - 真实表同型货占比高（GB-3/FD-1/IB-1/IB-2 共 91 件），默认 `weight_order` + `pn_continuous` 会拆散它们。
   - 建议：补充主数据时对无 PN 的同 PackMatls 视为同一堆叠族；计算页提供「真实混装」预设：关 `weight_order`、开 `same_type_stack`。
   - 铲齿 1220 mm：FD-1 长边 1470 超限，旋转后 1150 才能进叉，算法已旋转，但应在预览里标出「必须旋转」。

5. **未分配原因**
   - maxspace / extreme_point / wall_build / guillotine 未调用 `_unassign_reason`，UI 只显示「未分配」。
   - 建议：统一走 `_unassign_reason`，区分载重/高度/叉车路径/无箱位，便于补主数据或改规则。

6. **空 PN 排序**
   - `order_items` 把无 PN 放到最后。3 件漏装全是空 PN 的 IB-1（1.85 m³ 大件），碎片空间塞不进。
   - 建议：无 PN 也按体积/毛重插入大件队列，避免大件垫底。

7. **wall_build / guillotine 不适合本货型**
   - 完成率 11%–32%，真实混装默认算法建议只跑 maxspace + dblf；或给 wall_build 补「多层 + 换排」后再开放。

### 限制排序

**1. 铲齿 1220 mm（对人工方案杀伤最大）**

`fork_tine` 默认开启：叉车件的进深边 `dx` 不得超过 1220。IB-1/FD-1/GB-3 长边 1460/1470/1400，算法只能把短边当进深、长边当宽度：

| 货型 | 人工取向（长边进深） | 算法取向（短边进深） |
|---|---|---|
| IB-1 1460×1150 | 地板 8×2=16，余宽 52 mm | 地板 10×1=10，余宽 **892 mm** |
| FD-1 1470×1150 | 地板 8×2=16，余宽 52 mm | 地板 10×1=10，余宽 **882 mm** |
| GB-3 1400×1140 | 地板 8×2=16，余宽 72 mm | 地板 10×1=10，余宽 **952 mm** |

78 件有一边超过 1220。人工把长边沿箱长摆、宽度排两列；算法被铲齿逼成单列，每箱宽度浪费约 0.9 m。这是 4×40GP 装不满的第一原因。

**2. 装填策略：混尺寸贪心，同型不铺层**

即使关掉铲齿，4×40GP 完成率仍 81.7%。maxspace 按 PN 链 + 无 PN 垫底插入，同型（GB-3 28 件、FD-1 20、IB-1 18）被拆散，高度参差，空腔无法再塞大件。人工是同型砌墙：先铺满一层再上二层。

**3. 40GP 门高 2280 mm**

`max_z = min(inner_h, door_h) = 2280`。FD-1 高 1220，二层 2440 > 2280，只能一层（20+1+2=23 件）。人工同样一层，靠地板 8×2 排满；算法在限制 1 下只剩 10 个地板位。

**4. 默认软规则**

`rules_json=None` 时 `weight_order`、`pn_continuous`、`fork_tine` 全开。IB-1 毛重 164–1210 kg，轻重规则几乎禁止互压。

**5. 叉车路径硬规则 + 卸货校验**

`fork_reachable` 始终生效；方案即使摆进去，回放仍大量 E106/E103。人工卸货路径更灵活。

### 优化方向（对准 4×40GP）

1. 铲齿改为「可进铲的边 ≤1220 即可」，允许长边沿箱长、短边朝门（四面进铲语义）。IB-1/FD-1/GB-3 恢复 8×2 地板。
2. 同型优先砌墙：按 PackMatls 分组，先 FD-1/IB-1/GB-3 铺满层，VEN 填缝。
3. 计算页「人工混装」预设：关 `fork_tine` 与 `weight_order`，开同型铺层。
4. 无 PN 大件按体积插入队列，避免 IB-1 垫底。
